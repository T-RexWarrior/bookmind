# 二叉树：从结构到遍历

这是一份用于体验 BookMind 的示例学习资料，内容为本项目编写，不是外部教材摘录。

学习目标：理解二叉树的结构，区分前序、中序、后序遍历，并能手动推导一个小例子的遍历顺序。

## 1. 什么是二叉树

二叉树是一种树形结构，每个节点最多有两个子节点，分别称为左子节点和右子节点。左、右有明确区别，不能随意交换。没有子节点的节点称为叶节点。最上方的节点称为根节点。

例如，A 是根节点；A 的左子节点为 B，右子节点为 C；B 的左子节点为 D，右子节点为 E；C 没有子节点。这个二叉树有 5 个节点，叶节点为 D、E 和 C。

二叉树的递归特点是：根的左子树和右子树本身也都是二叉树。因此，处理整棵树的问题可以拆成“处理根节点、处理左子树、处理右子树”三个部分。

注意：二叉树不一定是二叉搜索树。普通二叉树只约束节点的子节点数量，不要求数值的大小关系。二叉搜索树才要求左子树的值小于根、右子树的值大于根（这里假定键不重复）。

## 2. 三种深度优先遍历

遍历指按某个顺序访问所有节点，每个节点恰好访问一次。“前、中、后”说的是根节点相对于左右子树的访问时机。三种遍历中，都先处理左子树，再处理右子树。

前序遍历的顺序是：根节点、左子树、右子树。对于 A 为根、B 为 A 的左子节点、C 为 A 的右子节点、D 和 E 分别为 B 的左子节点和右子节点的二叉树，前序遍历的结果为 A、B、D、E、C。

中序遍历的顺序是：左子树、根节点、右子树。对同一棵树，中序遍历的结果为 D、B、E、A、C。只有当这棵树同时满足二叉搜索树的条件时，中序遍历才会得到按键值递增的序列；普通二叉树没有这个保证。

后序遍历的顺序是：左子树、右子树、根节点。对同一棵树，后序遍历的结果为 D、E、B、C、A。它适合先处理子问题、再汇总到父节点的情形，例如计算子树信息或释放树节点。

递归遍历遇到空节点时立即返回。在每个非空节点上，只有“访问当前节点”这条语句的位置不同。访问放在两次递归之前就是前序，放在两次递归之间就是中序，放在两次递归之后就是后序。

```python
def inorder(node):
    if node is None:
        return
    inorder(node.left)
    print(node.value)
    inorder(node.right)
```

对有 n 个节点的二叉树，三种遍历都恰好访问每个节点一次，时间复杂度为 O(n)。递归调用栈的额外空间为 O(h)，其中 h 为树高；最坏情况下退化成链，h 可达到 n。

## 3. 层序遍历与常见误解

层序遍历按照从上到下、同层从左到右的顺序访问节点，通常使用先进先出的队列。对示例树，层序遍历的结果为 A、B、C、D、E。

具体步骤是：将根节点入队；只要队列不为空，就取出队首节点并访问它；如果有左子节点，将其入队；如果有右子节点，将其入队；重复这个过程直到队列为空。

深度优先遍历一般使用递归或栈，层序遍历使用队列。前序、中序、后序不是按“整棵树中的左边或右边”简单排序，而是对每棵子树重复同一条规则。

判断一种遍历顺序时，可以先找到根在输出中的位置：前序的第一个是根，后序的最后一个是根，中序中根位于左子树输出与右子树输出之间。仅凭一条前序、中序或后序序列，通常无法唯一确定二叉树的结构。
