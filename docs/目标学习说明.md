# 从目标生成学习资料

书架保留两个起点：“已有资料”导入教材；“已有目标”进入 `/learning/goals`。两者最终进入同一套“自主学习｜AI 导学｜练习巩固｜学习笔记”。

## 使用流程

1. 输入学习目标、已有基础和要求，选择精简、标准或深入。
2. AI 拟定学习方案，可修改标题、学习范围、适合程度和预计章节数。
3. 确认方案后生成目录。可调整章节标题、学习目标、说明、顺序，也可增删章节。
4. 确认目录后逐章生成，页面展示实际章节状态。可暂停、继续，或重试未完成的章节。离开页面后，书架仍能恢复生成记录。
5. 完整生成后可下载 Markdown；点击“加入教材并开始学习”，建立本书的阅读工作区、导学路径和笔记本。练习直接使用同一份生成资料。

## 复用的原版实现

- 恢复 `deeptutor/api/routers/book.py` 的 REST 与 `/ws/books` 接口注册。
- 前端直接调用保留的 `web/lib/book-api.ts`，执行 `create`、`confirmProposal`、`confirmSpine`、`pause`、`resume`、`compilePage`。
- 方案来自 `IdeationAgent`；目录由 `SourceExplorer` 与 `SpineSynthesizer` 组织；正文由 `BookEngine`、`BookCompiler`、原版章节规划及内容块生成器编写。没有增加另一个书籍生成 Agent。
- 当前目标入口不附加知识库或外部素材；支持文字、章节正文、提示、代码示例、知识卡、时间线和练习块，使用已有文字模型配置。图解仍可在学习时按需调用。

## 如何接入共同的学习记录

`deeptutor/bookmind/generated.py` 使用原版 Markdown 导出器读取完成的 Books 内容，再用原版 ReadingStore 导入，最后调用已有教材绑定逻辑。服务端会检查章节、正文块和目录是否完整，避免把未完成的生成结果标成可学习资料。

`generated_sources` 只保存原版书籍与阅读资料的对应关系、来源版本和学习目标，不保存第二份掌握分数。不同生成任务有各自的资料身份；重复导入同一任务会返回原来的教材、路径和笔记本。导入后的正文作为不可变快照，重新打开生成记录不会覆盖学习笔记、引用位置或作答证据。

## 验证

- 教材关联、来源范围、作答证据、目标资料导入、失败内容拦截、重复导入、不同生成任务隔离，以及原版掌握规则与复习调度共 125 项后端检查。
- `web/scripts/check-bookmind-goals.mjs` 检查 Books 接口、两个起点和手机表单；加 `--live` 会调用实际模型，执行方案、目录、章节生成、刷新恢复、导入和四个学习页面的完整联调。
- 真实联调使用独立的“二叉树入门 · 目标生成演示”，生成结果与截图保存在忽略提交的 `data/goal-verification/`，不代表真实学生的学习成绩。

API 密钥、学习资料、生成记录和本机依赖不提交到 Git。
