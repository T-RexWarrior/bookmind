# PDF 阅读修复（2026-10-27）

用户上传的数据结构教材共 669 页，约 44MB，已完整入库，文件未损坏。独立打开时可显示；排查翻页流程时，复现了 `Cannot set properties of null (setting 'width')`。

原因是学习页切换页码时，等待新页文字会临时移除 PDF 阅读组件。绘制任务仍在等待字体或页面数据，返回时画布已被移除，且 React 的异步清理还没有执行，因而存在竞态。每次移除组件也会导致下一页重新打开整份 PDF。

修复内容：

- 原版阅读不再等待新页文字请求，翻页保留同一个 PDF 阅读器和已打开的文档。
- 重用画布前取消并等待上一任务；异步结果返回后核对画布仍存在；已退出的阅读器不会触发模式切换。
- 页面绘制与文字选区分开处理，文字选区失败不再让已绘制页面报错；文字处理超时可改用原文位置。
- 提供按页绘制的兼容显示；200 页及以上教材默认采用它。使用本机 PyMuPDF，不调用图像模型，不修改原文件。画布出错或打开超时也可自动切换。
- 兼容显示仍覆盖可选择的原文文字位置；划选复制省略换行空格时，后端恢复对应的原文片段，仍拒绝原文中不存在的措辞。
- 页面缓存保存在 `data/pdf-pages/`，可复用，单张图限制分辨率与像素数。图片与原文位置接口均校验资料归属和页码。

验证：后端 14 项检查通过，包括新增的像素、缓存、文字位置、空白页、资料归属、尺寸限制和选区核对检查。新增 4 项浏览器检查通过：翻页保留画布且不重复下载、文字层故障时保留原文、画布故障时自动兼容显示，以及本机 669 页教材的封面、26、100、669 页与划选。原有 PDF 阅读、翻页、划选与文字视图检查也通过。
