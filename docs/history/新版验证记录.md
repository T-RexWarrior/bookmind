独立演示教材上的真实 DeepSeek 联调完成：

1. 从上传界面导入资料，建立原版阅读工作区、路径和笔记本的共同关联。
2. 阅读助教基于原文给出带来源的回答。
3. 原版小测生成三道题，提交前的响应不含答案；提交后产生同一路径中三条学习证据和复习安排。
4. 原版 Mastery 路径助教生成可作答题卡；故意提交错误选项后，原版统一记录中出现本书错题。
5. 通过原版保存弹窗创建笔记，默认选择本书笔记本，保存教材、目标和原文位置。
6. 从笔记中的来源链接返回原版阅读器；本书错题页显示原版错题卡。

这组操作由测试代理执行，位于单独的「二叉树 · 学习闭环演示」教材，不代表真实学生已经掌握。原有四份资料和两条笔记已从 v2 只读复制，v2 的作答结果没有猜测映射为新目标的证据。

实拍截图和详细结果在本机 `data/native-live/`、`data/native-verification/`，包含运行数据，不提交到源码仓库。绿色芽苗图标的文件 SHA-256 与旧版相同。API 配置、用户资料、本机环境及缓存均在忽略提交的目录。
