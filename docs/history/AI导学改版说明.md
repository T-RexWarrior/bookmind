# 自主学习与 AI 导学改版

本次在 `snapshot/2026-10-28-native-v1` 的基础上调整，继续使用 BookMind 原版 Reading、Mastery、Notebook 和 Assessment 实现，不重建三套核心引擎。

## 页面与操作

- 教材标题下方、靠左排列四个平级入口：“自主学习｜AI 导学｜练习巩固｜学习笔记”，不再在“学习”下面嵌套两种模式。练习的配置和答题内容在剩余高度内独立滚动，上方页面入口和练习分类保持可见。
- 自主学习使用原版阅读器与阅读对话，保留聊天、出题、可视化、追问等有效入口。
- AI 导学使用原版学习地图和教学会话，操作名称统一为“随堂测验｜图解说明｜补充示例”。随堂测验让导学老师针对当前知识点安排题卡，在学生回答后反馈；不等同于整组专项练习。题卡、未完成问题和掌握判断仍由原版引擎负责。
- 练习巩固独立为 `/learning/practice/{path_id}`，包含“专项练习｜错题本｜复习计划”。专项练习恢复原版 `QuestionPipeline` 的探索、规划和逐题生成流程，以及 `QuizConfigPanel`、`QuizViewer` 和题目追问组件，不再借用固定三题的 Reading Quiz。
- 配置支持题数 1–50、自动/简单/中等/困难、选择/判断/填空/简答/论述/编程六种题型、多题型数量配比，以及补充要求。选取同一知识点内最多 24 个原文单元，通过原版阅读引用解析器提供正文，不依赖嵌入模型。参考试卷仿题不放进当前教材练习页面。
- 每本书使用独立的原版练习会话；每轮记录不可混用的教材、知识点和原文范围。作答关联由服务端从实际生成事件恢复，客户端不能替换答案或知识点。客观题判分后进入同一学习证据和复习队列，批量结果与单题提交重复到达不会重复计分。错题复练也能追加真实作答证据。
- 简答、论述和编程题保留参考答案、AI 评阅和追问；主观题评阅意见不直接转成“已掌握”。未判定的作答保存为待评估，不混进已判错的题目列表。
- AI 导学保留原版 `/learning/mastery/{path_id}` 路由，API 返回独立的 `links.guide`。现有教材、路径、笔记和会话 ID 保持兼容，无需迁移或清空学习数据。
- 同一浏览器标签页按教材记住两种学习模式各自的最近会话地址，来回切换可继续各自的会话；不把另一教材的会话地址带入。

## 原文与学习记录

- AI 导学可随时打开当前知识点的教材原文侧栏，支持文本、上一页/下一页，以及 PDF 原页预览；可进一步进入完整阅读器。
- 模型实际执行阅读工具后，回答中的来源标记和“查阅原文”入口可打开对应位置。来源身份从该轮实际工具结果获取，不能用当前界面碰巧打开的教材替代；不同版本的引用也不静默跳到新版本。
- 导学材料提示要求引用前核对原文并给出实际页码。模型单独写出的页码不是验证证据。
- 原文侧栏独立于 Reading 的文档状态，不会因为核对来源而改变自主学习中的阅读位置。
- 正式自测与导学作答继续共用原版评估、证据和复习机制；一次选择题答对不会直接认定整个概念已掌握。

## 可用能力与品牌

- 本版只启用文字模型相关的可选工具，以及 SVG、Chart.js、Mermaid、思维导图和 HTML 图解。
- 联网搜索、论文库、Zotero、GeoGebra 独立工具、图像生成、视频和语音服务暂未开放。后端对显式请求的可选工具也执行限制，前端设置说明真实范围；可视化菜单不显示未接入的动画、故事板或插件安装入口。
- 统一主要页面、登录/注册、设置说明、教学提示词、API 欢迎信息与项目描述中的 BookMind 品牌。产品名使用大写 B、M；绿色芽苗图标保留。
- 继续保留 `bookmind` 内部包名、导入路径、环境变量及存储键，确保原版运行时和既有数据兼容；上游版权、许可证与来源说明保留。
- 减少重复信息栏，调整中文字体、模式导航、练习卡片与手机布局。文字笔记和图解继续按原版分开保存。

## 仍保留的能力边界

- 初始学习目标仍主要从目录建立，不宣称已经逐页分析整本书；可使用原版大纲编辑及导学助手继续细化，并保留来源。
- 当前按页读取和文本检索，没有配置嵌入模型，也没有完整复刻语义向量检索。
- 专项练习依据所选知识点内的原文范围出题，不把局部练习成绩当成整章掌握；阅读时的轻量小测仍保留固定三题的原版设计。
- 阅读小测继续使用原版同位置待答题机制。专项练习按原版会话和生成轮次保存，每轮答案互不混用，重新出题不覆盖已提交的作答；重新打开页面恢复最近一组完成的练习。
- 原版未开放功能的共享源码仍有保留，内部包名迁移和更深的依赖清理尚未进行。

## 目录与聊天图解优化（2026-10-28）

- 部分 PDF 书签使用 Wingdings 私用字符（例如 `U+F06E`）作为项目符号，缺少对应字体时显示为方框。导入时和读取旧目录时清理已知的装饰前缀，保留标题、页码、层级、数学符号与原文；无需重新导入，也不重写标注与作答来源。
- 普通阅读/导学对话现在可以直接调用原版 `submit_visualization`，复用原版图解校验器与 `VisualizationViewer`，与文字解释共同显示。图解数据随工具结果保存，事件预览收缩时优先保留，因此刷新后仍可恢复。
- 默认 SVG 图解按聊天栏的宽度设计，控制节点、间距与标签字号；保留原版放大、代码查看等操作。文字模型生成 SVG 不需要图像生成 API，也不需要开放代码执行。
- SVG 文字尊重图形自己声明的基线，不再全局强制居中，避免与已有的 y/dy 偏移叠加。仅对明确位于节点中心、未声明基线的旧标签补充中心基线；显式基线、多行文字和变换保持原布局。新生成的节点标签明确使用中心坐标与中心基线，已有图解重新打开即可应用渲染修正。
- 引用已读原文优先使用可点击来源，按需定位，不再要求每处引用都跳转。BookMind 的文字模型流程不挂载不可用的 `view_figure`，避免为普通示意图反复尝试读取图片像素。原图复刻仍需要可用的视觉能力，不能把自绘示意说成教材原图。
- 简单图解聚焦用户所问，不因关联了笔记而扩展成无关讲义。检索、阅读按需要调用，不以固定次数限制复杂问题。
