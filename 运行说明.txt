学迹 BookMind 评委运行说明

系统要求
Windows 10 或 Windows 11 64 位系统。无需预装 Python、Node.js 或数据库。

运行方法
1. 解压整个可运行程序压缩包。
2. 双击 BookMind.exe，保留弹出的运行窗口。
3. 浏览器会自动打开 http://127.0.0.1:18765/ui/。
4. 可创建演示学习空间，或新建学习空间后上传 PDF 资料。
5. 体验结束后关闭 BookMind 运行窗口。

模型配置
程序已配置 qwen-chat 作为主要问答模型，并在请求失败时自动切换 glm-5.3-flash。
向量模型为 qwen3-embedding，重排模型为 qwen3-reranker。
模型 API 配置已放入 .env，使用模型功能时需要联网。

如果页面提示“模型暂不可用”并显示 Windows 错误 10013，说明本机防火墙、代理或安全软件阻止了程序访问模型网关。请允许 BookMind.exe 进行外网 HTTPS/443 访问后，关闭并重新打开 BookMind.exe。页面右侧的资料检索仍可在模型暂不可用时工作，但问答会暂时退回资料摘录。

数据说明
数据库、上传资料和索引会在首次运行后写入 data 文件夹。
提交包不包含参赛者个人学习记录、测试聊天、教材文件或历史数据库。

常见问题
若 Windows SmartScreen 提示风险，请选择“更多信息”后确认运行。
若浏览器未自动打开，请手动访问 http://127.0.0.1:18765/ui/。
若 18765 端口被占用，请先关闭旧的 BookMind 运行窗口。
